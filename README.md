# Phishing Intelligence and Investigation Assistant

An explainable investigation assistant for suspicious URLs. It combines lexical and obfuscation checks, PhishTank and URLhaus lookups and a machine-learning signal into a 0-100 risk score, with history, a dashboard and exportable reports. URLs are never opened and are shown only in defanged text.

**Full documentation, setup steps and known limitations:** [phishing_intelligence_assistant/README.md](phishing_intelligence_assistant/README.md)
